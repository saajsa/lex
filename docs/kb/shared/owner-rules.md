How to read this ledger:
- **Status** is `current`, `superseded (by ...)` or `narrowed (by ...)`. A superseded rule is kept so a reader can see why old code or old notes look the way they do.
- Session refs: `3adfe568` is the Android session; `19acbaeb` and `89b46f22` are the Web agent's sessions; `fabd99ad` is an earlier web session. `C<n>` is a compaction summary of session 3adfe568. All times are UTC (the owner works in IST, UTC+5:30).
- Quotes are verbatim and short. Where only a compaction or memory note records a rule, the label says so.
